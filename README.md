A highly immersive, cinematic WebGL portfolio built for **Shiv Prakash Singh**, an AI Engineer & Full-Stack Developer. This project merges cutting-edge 3D web graphics with an autonomous AI assistant powered by Google's Gemini LLM.

## ✨ Features

- **Cinematic WebGL Background:** A reactive 3D starfield and rotating wireframe geometry built with React Three Fiber.
- **The Holocron Guide (AI Chatbot):** A custom-built AI assistant using the Vercel AI SDK. It acts as an interactive resume, answering user queries via real-time streaming text.
- **Glassmorphic Asymmetrical UI:** A modern Awwwards-inspired layout with frosted glass containers, smooth scroll reveals, and 3D parallax tilt effects.
- **Bento Box Grid Layouts:** Clean, responsive categorization of skills and technical arsenals.

## 🚀 Tech Stack

- **Frontend:** Next.js 14 (App Router), React, TypeScript, Tailwind CSS
- **3D & Animation:** Three.js, `@react-three/fiber`, `@react-three/drei`, Framer Motion, `react-parallax-tilt`
- **AI Integration:** Vercel AI SDK (`@ai-sdk/react`, `@ai-sdk/google`), Google Gemini 2.5 Flash API

## 🛠️ Local Development

1. Clone the repository:
   ```bash
   git clone [https://github.com/yourusername/holocron-portfolio.git](https://github.com/yourusername/holocron-portfolio.git)
   ```

2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a .env.local file in the root directory and add your Google Gemini API key:
   ```bash
   GEMINI_API_KEY=your-gemini-api-key-here
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
